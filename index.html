Conventions

  • Shared header and footer blocks are marked <!-- HEADER START --> / <!-- FOOTER START -->.
  • Blocks labelled Mock-up state show other states of the same page. Remove them when you build the PHP views.
  • State-changing forms use method="post" action="#" and carry a csrf_token. Search and filter forms use GET.
