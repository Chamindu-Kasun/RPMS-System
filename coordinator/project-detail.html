Description
This project builds and evaluates an abstractive summariser for Sinhala news articles by fine-tuning a multilingual transformer model on a curated corpus of about 5,000 article–summary pairs collected from public news websites. It compares the model against an extractive baseline using ROUGE scores and a small human evaluation of fluency and faithfulness.
